# Трекер ЖК «Turan Palace»

Страница со списком проблем 2-й очереди ЖК «Turan Palace» (ул. Туран 83/2): кто отвечает, какие сроки обещали, сколько дней просрочки и по каким статьям законодательства РК требовать исполнения.

Данные собраны из чатов жильцов за 11.08–09.11.2026.

## Как устроено

Один статический файл `index.html`: без сборки и зависимостей. Список проблем лежит в массиве `I` внутри скрипта, статьи законов в объекте `L`. Дни просрочки считаются автоматически от текущей даты.

## Как обновить статус

В `index.html` найдите проблему по её `id` (например `"Ф-1"`) и поменяйте поле `st`:
`overdue` (просрочено), `nodate` (без срока), `progress` (в работе), `partial` (частично), `dispute` (спорно), `done` (решено).
Обещанная дата: поле `pd` в формате `ГГГГ-ММ-ДД` или `null`.

## Деплой на Vercel

Import Project → выбрать этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory `.` → Deploy.
